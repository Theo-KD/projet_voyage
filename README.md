# ✈️ Projet Voyage – Gestion de voyages en HTML/CSS/JS/PHP

Projet Voyage est une application web permettant de gérer des voyages, destinations et informations associées.  
Ce projet a été réalisé dans le cadre de ma formation en développement web, avec un design simple, responsive et une structure claire.

---

## 🚀 Fonctionnalités

- Affichage des destinations disponibles
- Consultation des détails d’un voyage
- Interface responsive en HTML/CSS
- Interactions dynamiques en JavaScript
- Gestion des données via PHP
- Organisation des pages et composants pour une navigation fluide

---

## 🛠️ Technologies utilisées

- **HTML5**
- **CSS3**
- **JavaScript**
- **PHP**
- **MySQL**
- **WAMP**
